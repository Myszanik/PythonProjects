# PythonProjects

A collection of small Python scripts and mini-projects for learning and practice. The repository is split into three folders.

## Project Overview

- **BasicScripts**, fundamental Python scripts covering algorithms, input/output, and simple validation.
- **GameDevelopmentScripts**, small games built in Python, including both text-based and simple GUI-based games.
- **ExpenseTrackerScripts**, scripts for splitting bills and calculating costs, with both console and GUI versions.

## Folder Structure

- `BasicScripts/`, core Python concepts and algorithms.
- `GameDevelopmentScripts/`, simple game projects in Python.
- `ExpenseTrackerScripts/`, expense and bill-splitting utilities.

## Requirements

- Python 3.x
- `tkinter`, usually comes pre-installed with Python
- `pygame`, only needed for scripts that use it

## How to Run

1. **Clone this repository**:
   ```bash
   git clone https://github.com/Myszanik/PythonProjects.git
2. **Navigate to the Project Directory**:
   ```bash
   cd ExpanseTrackerScripts
3. **Install Dependencies (optional)**:
   ```bash

4. **Run the Application**:

   python spli_bill_console.py
